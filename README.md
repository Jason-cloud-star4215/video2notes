# video2notes —— 视频一键转学习讲义 PDF

给一个视频链接，自动产出一份**结构化的学习讲义 PDF**：抓取标题与简介、获取字幕或做本地语音转写、清洗去重、抽取关键画面、重组成按"读者要理解什么"组织的讲义、编译成 PDF，并附一份体检报告。

---

## 一、它做了什么

```
视频链接
   │
   ├─ 1. 探测元数据        标题 / UP主 / 时长 / 封面 / 字幕轨 / 章节
   ├─ 2. 取讲解文本        平台字幕优先 ──(无字幕)──▶ 本地 Whisper 转写
   ├─ 3. 清洗去重          SRT 解析、滚动重复剔除、时间戳归一
   ├─ 4. 抽取关键画面      均匀抽帧（可调数量）
   ├─ 5. 重组讲义          调语言模型：完整覆盖 + 按理解顺序重排 + 保留时间锚点
   ├─ 6. 生成 LaTeX        自带模板（配色提示框 / 公式 / 表格 / 代码 / 图注）
   ├─ 7. 编译 PDF          xelatex 两遍
   └─ 8. 体检报告          字幕覆盖率 / 讲义与转写字数比 / token 用量 / 可疑点
```

**设计取向**：不是"做一份漂亮的摘要"，而是**尽量不丢内容**。讲义里每个知识点都带视频时间点，方便回查原片。

## 二、安装

### 1. 必需组件

| 组件 | 用途 | 检查方式 |
|---|---|---|
| Python 3.11 | 运行脚本 | `python --version` |
| yt-dlp | 下载视频/字幕 | `yt-dlp --version` |
| ffmpeg + ffprobe | 抽音轨、抽帧 | `ffmpeg -version` |
| MiKTeX / TeX Live（xelatex） | 编译 PDF | `xelatex --version` |

**Python 包**（缺哪个装哪个）：

```bash
# 首选：faster-whisper（支持国内镜像，速度快、显存占用低）
python -m pip install faster-whisper requests numpy

# 备选：openai-whisper（其官方模型源在国内常不可达，仅在没有前者时作为回退）
python -m pip install openai-whisper torch
```

> 只处理**有平台字幕**的视频时，转写相关包可以不装——脚本会自动走字幕路径。
> 但**无字幕视频必须**有转写后端。

**关于模型下载**：脚本默认使用 `faster-whisper`，并通过 `HF_ENDPOINT` 走国内镜像
（默认 `https://hf-mirror.com`，可用环境变量覆盖）。首次运行会下载模型（数百 MB ~ 1.6 GB），
之后复用本地缓存。

```powershell
# 若想换镜像
$env:HF_ENDPOINT = "https://hf-mirror.com"
```

### 2. 语言模型密钥（可选，但强烈建议）

没有密钥时脚本仍能运行，但只能产出「原始转写文稿」PDF，不会重组成讲义。

设置方式（任选其一）：

**方式 A：环境变量（推荐）**

```powershell
# 当前会话临时生效
$env:DEEPSEEK_API_KEY = "sk-你的密钥"

# 永久写入用户环境变量
setx DEEPSEEK_API_KEY "sk-你的密钥"
```

**方式 B：什么都不做**

脚本会自动从 `~/.codex/config.toml` 里读取已配置的 DeepSeek 密钥。

### 3. 环境自检

```bash
python video2notes.py --check
```

会逐项列出缺什么、以及对应的安装方式。

## 三、使用

### 方式 1：创建桌面快捷方式（推荐）

```bash
python video2notes.py --install-shortcut
```

桌面上会出现 `视频转讲义.bat`。之后两种用法：

- **双击** → 按提示粘贴链接、回车
- **拖拽** → 把浏览器里的视频链接直接拖到这个文件上

### 方式 2：命令行

```bash
python video2notes.py "https://www.bilibili.com/video/BVxxxxxxxx"
python video2notes.py "https://youtu.be/xxxx" -o "D:\讲义" -m small
```

### 参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `url` | 视频链接（位置参数） | — |
| `-o, --output` | 输出根目录 | `桌面\视频讲义` |
| `-m, --model` | 本地转写模型 `tiny/base/small/medium/large/large-v3/large-v3-turbo` | `large-v3-turbo` |
| `-f, --frames` | 抽帧数量 | `12` |
| `--keep-media` | 保留视频/音频/帧等过程文件 | 关（自动清理） |
| `--check` | 只做环境自检 | — |
| `--install-shortcut` | 创建桌面快捷方式 | — |

> 抽帧数建议：11 分钟视频用 8~12 张；60 分钟用 20~25 张。

## 四、输出

每讲一个文件夹，例如 `桌面\视频讲义\MySQL 数据库零基础入门 · 第 01 讲：数据库基本概念\`：

| 文件 | 说明 |
|---|---|
| `notes.pdf` | **讲义成品**（要读的就是它） |
| `notes.tex` | LaTeX 源码，想改版式可以直接编 |
| `transcript_indexed.txt` | 带时间点的完整转写，用来按时间回查原话 |
| `audio.srt` | 逐句字幕，可导入播放器对照 |
| `视频简介.txt` | 视频简介 |
| `metadata.json` | 元数据（标题/时长/字幕轨等） |
| `体检报告.txt` | **先看这个**——判断这份讲义靠不靠谱 |
| `run.log` | 完整运行日志 |
| `cover.jpg` | 视频封面（若有） |

### 体检报告怎么读

重点看四项：

1. **字幕来源** — 是平台字幕（更准）还是本地转写（可能有错字）
2. **转写覆盖率** — 低于 90% 说明有大段没转上，可能有内容缺失
3. **讲义/转写 比** — 正常在 1.0~1.6 之间；超过 1.6 建议抽查是否有模型自行补充的内容
4. **PDF 可提取汉字** — 有数字说明中文可检索可复制；为 0 说明字体有问题

## 五、常见问题

**Q：提示"该视频没有可用字幕"**
A：多数情况是**未登录**。B 站对未登录请求不返回字幕清单。解决办法：

```bash
yt-dlp --cookies-from-browser edge --write-subs --skip-download "视频链接"
```

拿到 `.srt` 后再手动处理。脚本目前不读浏览器 cookie（涉及隐私，需你明确授权才做）。

**Q：转写出来错字多**
A：本地 Whisper 对中文技术术语容易听错（"关系型"→"观型"）。可以在脚本目录建 `glossary.txt` 存纠正词表，一行一条 `错误写法=正确写法`，脚本会在后续版本中支持。当前版本可在生成讲义后手工核对 `transcript_indexed.txt`。

**Q：编译失败 / 缺宏包**
A：MiKTeX 首次遇到缺失宏包会询问是否安装。若有问题运行：

```bash
miktex --admin packages update-package-database
```

**Q：PDF 中文不能搜索、不能复制**
A：字体问题。脚本默认使用 Windows 系统字体（SimSun），一般不会有此问题。若仍出现，检查是否装了 `ctex` 宏包。

**Q：处理一个视频花多少钱**
A：脚本只调用**一次**语言模型（生成讲义），成本主要在输出 token。11 分钟视频实测约 **¥0.06**（DeepSeek 空闲时段价；高峰时段约 ¥0.12）。体检报告里会记录实际 token 用量。

**Q：能处理哪些平台**
A：凡 yt-dlp 支持的都行——B 站、YouTube、抖音、小红书、腾讯视频等数百个站点。

**Q：视频没有字幕，转写太慢**
A：换小模型（`-m small` 或 `-m base`）能显著加快，代价是错字更多。默认的 `large-v3-turbo` 在你的显卡（RTX 5070 Ti）上实测 11 分钟音频转写约 30 秒，一般无需换小模型。

## 七、已知限制

1. **不做图片内容识别**。抽出的帧直接按时间插入讲义，图注为时间点。若要"读板书/公式并转 LaTeX"，需要接入视觉模型，当前版本未做。
2. **不做覆盖门禁**。相比 lecture-to-notes 的 `teaching_atoms.tsv` 硬门禁，本脚本用体检报告里的"讲义/转写比"做**软性提示**，不会阻断输出。
3. **单次 LLM 调用**。省钱的代价是：如果模型漏了知识点，脚本不会自动补。因此建议每次都看一眼体检报告的比值。
4. **不读浏览器 cookie**。需要登录态的视频（1080P+、大会员内容）可能拿不到字暮，会回退到转写。

---

## 八、建议的使用节奏

1. **先跑一遍**，看体检报告，判断这份讲义靠不靠谱
2. **通读讲义**，对照文末「自测与检验」自问一遍，答不出的回看时间点
3. **隔几天再做一遍自测题** —— 分散重做比连续重复有效得多
4. **只做你真正会反复回看的课**，不要一次铺开整门课

判断这套流程有没有用的标准，不是生成了多少页 PDF，而是：

> **合上讲义，能不能用自己的话把它讲一遍。**

本工具为 **AI 辅助开发**：需求定义、方案取舍、逐次验收与实战迭代由本人完成，代码主体由 AI 生成。灵感源自开源工具 [lecture-to-notes](https://github.com/ysyecust/lecture-to-notes)（ysyecust）——在使用中因交付硬门禁与重型流程不适配个人工作流，遂自建轻量版。已在本人 9 月课程学习中完成 85+ 次真实视频的产线运行验证（讲义目录另存，因含第三方课程内容不入本仓库）。
